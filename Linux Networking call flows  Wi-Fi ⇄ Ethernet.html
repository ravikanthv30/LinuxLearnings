The iptables column only applies when the br_netfilter module is loaded and net.bridge.bridge-nf-call-iptables (or -ip6tables, -arptables) is 1. Without it, only the ebtables/nft bridge rules run on bridged frames. The row for the current step is highlighted.

Header handling by protocol

HeaderWhere it is handledWhat happens
802.11 + LLC/SNAPieee80211_data_to_8023(), ieee80211_build_hdr()Converted to and from Ethernet framing; addr1-4 chosen by ToDS/FromDS; QoS field maps DSCP to a WMM queue
Etherneteth_type_trans(), br_handle_frame()Sets pkt_type and protocol and pulls 14 bytes; link-local frames (01:80:C2:00:00:0x: STP, LLDP) are consumed or forwarded per group_fwd_mask
802.1Q / 802.1advlan_do_receive(), br_allowed_ingress(), br_handle_vlan(), validate_xmit_skb()Hardware tag lives in skb->vlan_tci; bridge applies PVID and VID filtering; tag is pushed back into the payload if the egress NIC cannot insert it
IPv4 / IPv6br_validate_ipv4/6(), nf_ct_bridge_pre()Header sanity checks and trimming; fragments are reassembled for tracking and refragmented on egress (br_ip_fragment)
TCP / UDP / ICMPnf_ct_get_tuple(), tcp_pkt_to_tuple(), udp_pkt_to_tuple(), GRO/GSOPorts (or ICMP type/code/id) form the conntrack tuple; checksums are verified or trusted via skb->ip_summed; GRO merges segments in, GSO splits them out
conntrack statenf_conntrack_in(), __nf_conntrack_confirm()Entry is created unconfirmed, updated by the L4 state machine, and confirmed at POST_ROUTING
Bridge FDBbr_fdb_update(), br_fdb_find_rcu(), br_flood()Maps (MAC, VID) to a port, learned from the source MAC of each received frame; ageing_time defaults to 300 s; a miss floods. Inspect with bridge fdb show
Neighbour tablesneigh_resolve_output(), arp_process(), neigh_update(), br_do_proxy_suppress_arp()Maps IP to MAC on each host (and on br0 if it has an IP) through the states INCOMPLETE, REACHABLE, STALE, DELAY, PROBE and FAILED. Inspect with ip neigh show dev br0
ARPbr_flood(), br_nf_forward_arp(), arp_rcv()The request is broadcast and flooded; the reply is unicast and follows the FDB. The bridge itself never resolves IPs unless neigh suppression is on
ARP, IGMP/MLD, NDbr_nf_forward_arp(), br_multicast_rcv(), br_do_suppress_nd()arptables hooks; multicast snooping parses IGMP/MLD reports; neighbor suppression answers ARP/ND locally
Function names follow mainline Linux (~6.x). Driver-specific names vary by chipset (ath9k, iwlwifi, mt76, igb, r8169, stmmac…); <drv> marks those points.
